## Getting started

A Next.js (App Router) site with Tailwind CSS v4 and [Motion](https://motion.dev).

```bash
npm install
npm run dev
```

Open http://localhost:3000. The homepage lives in `src/app/page.tsx`, with the
hero and image grid in `src/components/`. Placeholder images come from
[picsum.photos](https://picsum.photos) (allowed in `next.config.ts`).
